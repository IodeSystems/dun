Twice, live, the model invented an opaque id instead of reading the one it was
given (`exec_2`, which matched nothing). Ids the model must copy are a failure
point; human-readable keys (the question a memory answers, a unique substring
like Hermes' patch/remove) are what it actually reproduces.
