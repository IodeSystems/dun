## Plist parity (the rendered LaunchAgent relaunches on the handover's exit)

The handover exits 75. The rendered LaunchAgent must treat 75 as a
non-successful exit so launchd relaunches it after `ThrottleInterval`. This
block asserts the plist carries `ThrottleInterval=3` (and that
`TestRenderLaunchAgent`, which checks it, passes in the default suite).

```sh produces=plist.log inputs=internal/dundcli/service_test.go,internal/dundcli/service_launchd.go
set -euo pipefail
cd "$(pwd)"
# The handover's exit (75) is not a successful exit in the rendered agent, so
# launchd relaunches after ThrottleInterval; this is what the plist must say.
GOWORK=off go test ./internal/dundcli/ -run 'TestRenderLaunchAgent' -count=1 -v 2>&1 | tee "$OUT/plist.log"
grep -q -- 'ThrottleInterval' internal/dundcli/service_test.go
echo "plist parity: ThrottleInterval=3 asserted and TestRenderLaunchAgent passes"
```

## Launchd handover: the exit-75 restart completes as under systemd

Given a dund under launchd (label in `XPC_SERVICE_NAME`, a manager with the
rendered agent's `KeepAlive.SuccessfulExit=false` semantics) with a pending
self-upgrade, when dund reaches the quiet point: the handover copies the new
binary over the unit's binary and exits 75, and the manager relaunches it.
This block runs the opt-in e2e (`DUN_TEST_LAUNCHD=1`): the turn's tokens cross
the restart in order, none lost and none twice, the engine is adopted on the
new build, and dund's log says it is "exiting 75 for the service manager".

```sh produces=launchd.log inputs=cmd/dun/adopt_integration_test.go
set -euo pipefail
cd "$(pwd)"
# The launchd half of the TC: dund under a launchd-semantics manager, a pending
# self-upgrade, the quiet-point handover (copy the new binary over the unit's,
# exit 75), and the manager's relaunch completing the restart as under systemd.
# Opt-in behind DUN_TEST_LAUNCHD=1 (not in the declared check; the real
# launchd relaunch runs on a Mac under the ops plan).
GOWORK=off DUN_TEST_LAUNCHD=1 go test ./cmd/dun/ -run 'TestAdoptAcrossLaunchdHandover' -count=1 -v -timeout 300s 2>&1 | tee "$OUT/launchd.log"
grep -q -- '-- PASS: TestAdoptAcrossLaunchdHandover' "$OUT/launchd.log"
echo "launchd handover: exit-75 restart completes, tokens cross, engine adopted"
```
